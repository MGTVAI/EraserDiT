# L40S 优化收敛与验收

目标：完成路线图中本轮优化的实现、验证或有证据的候选淘汰，推荐配置每卡任务进程合计峰值不超过24 GiB；
最终按 L40S 单卡、双卡、四卡的同条件结果重写 README。16 GiB 与其他显卡实机验证保留为长期方向。

## 验收口径

- 1080p、原始帧数、50步×strength 0.8，每窗口实际去噪40步；121帧窗口、9帧重叠，不缩短尾窗填充。
- 显存覆盖加载、预热、推理和退出；同时记录 allocated、reserved、NVML每卡任务进程之和及整卡占用。
  `--cuda-memory-limit-gib 22` 是每进程分配器预算，不能代替同卡多进程合计实测。
- 推荐配置同条件至少五次请求，加载与预热单列；报告请求中位数、范围和阶段耗时。
- 精确路径比较完整输出；文件哈希一致可证明解码像素一致。近似候选报告整帧、mask、边缘、最差帧和时序误差，保存对照图。
  初筛平均整帧与mask SSIM均须≥0.985；视觉检查单列，SSIM不代表擦除成功，也不能单独证明没有闪烁。
- 两个本地原始素材、seed 42/7、多窗口、连续任务、取消与故障恢复；失败的初筛候选不继续扩展seed。
- 只使用空闲GPU，保留完整参数、输入/模型/源码指纹及依赖记录；正式性能测试期间不运行本轮辅助实验。

## 已收敛的配置决定

- 单卡使用BF16/SDPA、原生QK/AdaLN融合、DiT组件卸载、T5/VAE卸载、VAE低内存与uint8流式缓存。
- 双卡使用独立NCCL CFG2；四卡单视频使用CFG2×SP2的`reference`模式。
  两者在两个原始素材、两个seed上均与单卡BF16逐字节一致，四卡最高单卡任务峰值21.746 GiB。
- `sharded` SP允许BF16 GEMM形状改变，本轮四项质量未通过；不能将该结果推广到已通过的`reference`模式。
- Sage、动态/静态FP8、快速QK/AdaLN组合均保留为显式实验选项，不作为本轮通用推荐。
- 缓存0.1已比较TeaCache、CacheDiT前1/后0或后1、连续复用上限2；另依据探针距离测试TeaCache 0.01、CacheDiT 0.02。
  保守TeaCache在湖边仅复用1/40步仍未通过当前门槛，推荐关闭缓存。
- DP4 BF16 TeaCache四个相同145帧请求均与单worker同参数输出一致，各卡峰值20.682 GiB。
  这是功能与结果复现证据，不改变该缓存参数的质量淘汰结论。
- 输出通信重叠通用默认关闭；正式145帧四卡reference五次输出与BF16基准一致，
  head分块4使请求中位数从207.82 s降至195.93 s，峰值仍为21.746 GiB，纳入本轮L40S四卡推荐命令。
