## AdaLN→FP8 输入量化融合

继承 Q6 + S4 + Cross-Q RMSNorm + 定点填充，保留原 Sage 主核。
将 FFN 前 Norm/AdaLN 的 BF16 中间输出与静态 FP8 激活量化合并，
在 kernel 内保留原 BF16 舍入，并增加显式预量化输入接口以避免重复量化。

- 局部 Norm/量化：0.7079→0.3132 ms；完整局部 FFN 加速 1.056×。
- 完整 ABBA 请求均值：249.716→248.816 秒，减少 0.360%；
  DiT：211.999→210.700 秒，减少 0.613%。四份视频均与继承基线逐字节一致。
- 当前三档配置均未纳入此项，以控制接口与实现复杂度。
  Q6c 的 FFN 输出融合已适配原 BF16 入口，不依赖该原型。

证据目录：`adaln_fp8_20261021_01/`；报告 `NormAdaLN到FP8融合实验报告.md`，
计时及检查见 `ab_summary.json`、`micro/results.json`、`selection.json`。

## Cross 残差与 Norm/AdaLN 双输出融合

参考路径继承上面的 AdaLN→FP8 原型。候选先形成原 BF16 残差 R，
再在同一 kernel 内输出 FFN 的 FP8 输入 Q；R 仍完整写回供 FFN 后残差连接使用。
省去一次独立 add 启动及后续 Norm 对 R 的一次逻辑读取，不能称为消除残差存储。

- 11 组局部测试中 R/Q 逐字节一致；局部 FFN 与最终门控残差输出也一致。
- 前段：0.89024→0.73062 ms；含 FFN 及最终残差：7.77209→7.58951 ms。
  按 4480 次调用外推前段约省 0.715 秒，约占当时请求的 0.288%。
- 输入主要为合成激活，部分检查使用真实检查点权重；没有真实完整去噪集成、
  完整视频或请求性能结果。仅保留研究原型；接入当前配置时需重新处理接口依赖。

证据目录：`residual_adaln_20261021_01/`；报告 `残差NormAdaLN融合局部研究报告.md`，
原型与检查见 `reproduction/residual_adaln_proto.py`、`micro/results.json`。

## 输入拼接的 dtype 往返

实际首个正式窗口捕获确认：当前 latent 为 BF16，cond_latents/mask_values 为 FP32；
拼接结果 FP32，在 autocast Linear 前转换为 BF16。每窗口预转固定条件可以减少转换。

- 实际投影权重及首窗输入上，GEMM 前 BF16 字节和投影输出均一致。
- 含输入投影的局部中位数：0.81256→0.75546 ms。
  按 160 次调用外推约省 0.0091 秒、约占当时请求的 0.0037%，还未扣窗口缓存构建。
- 每窗口额外 BF16 缓存约 8.031 MiB；每次重新转换的方案还增加部分局部开销。
  不可全局改变原 FP32 条件，因为它也用于初始化和调度。
- 用户决定停止此方向；未做完整视频，未纳入正式模型。诊断入口已移除并归档。

证据目录：`input_dtype_20261021_01/`；报告 `DiT输入dtype往返核实报告.md`，
细节见 `micro/results.json`、`decision.json`、`withdrawal_verified.json`。

## 文字投影与 Cross-attention KV 缓存

继承 Q6 + S4 + Cross-Q + 定点填充 + AdaLN→FP8，单变量开启已有
`cache_text_projections`；这与 S4 的 T5 session 缓存不同。

- 完整 ABBA 请求：248.411→249.403 秒，增加 0.399%；
  DiT：210.424→210.713 秒，增加 0.137%。四份编码输出一致。
- 每请求 caption 命中 156 次、各层 KV 命中 4368 次，窗口保留存储峰值 59 MiB；
  该量包含借用源张量，不全是新增分配。NVML 峰值均为 21.189 GiB。
- 检查了 CFG 分支隔离、按窗口释放和既有失效键；权重/LoRA 版本不在键中，
  不代表热更新安全。未验证并发服务、多 GPU 或 compile。
- 缓存机制有效，但没有测出请求收益，保持关闭。

证据目录：`text_kv_20261021_01/`；报告 `文字投影KV缓存实验报告.md`，

## 纯 FFN GEMM 算法替换及 Q1/Q3 复核

保持原 Q6 静态 FP8、scale=.125、BF16 bias/output 与 fast_accum，
对 M32640/N8192/K2048 上投影和 M32640/N2048/K8192 下投影各筛出 8 个
cuBLASLt 启发式候选，workspace 上限 32 MiB；真实 block0/14/27 权重，合成激活。

- 最终交错局部计时，上投影当前模块 3.251 ms、候选0 3.336 ms；
  下投影当前 3.111 ms、候选0 3.074 ms。候选0与默认路径使用同名 kernel，
  其他复测分块未找到值得替换的收益，未做完整视频。
- 初版探针因绕过填充匹配产生额外 fill，已排除；最终对照验证填充策略一致。
  筛选不是算法全量穷举，也不是 INT8/FP8 功能性 FFN 的新对照。
- Q1/Q3 历史请求 407.365/402.654 秒属于旧 S3 初筛、不同批次，
  不是 FFN 独立计时。复核仅检查历史记录和实现，没有新 GPU 性能样本，
  不能据此认定静态 FP8 故障或宣称当前 FFN 只快约 1%。
- 原生 GEMM 输出融合 GELU＋FP8 是另一项实验，后来进入 Q6c；不属于本项未采用的纯算法替换。
  “BF16 位模式直接查最终 FP8 表”等建议仍未实现或测速。

证据：`core_gemm_20261022_01/gemm/results.json` 与上述主核/GEMM 筛选报告；

## Self-attention 输出投影 FP8

继承 QKV FP8 实验组合（含历史 AdaLN→FP8、Sage 外围、原 VAE），
捕获实际 Self-attention 输出投影输入。36 份局部留出覆盖两窗口、两 CFG 分支、
0/14/27 层和 steps1/19/39；全部 28 层 4480 次调用另收范围统计。

- 首轮含布局准备、量化、GEMM 与分配的局部调用：BF16 1.253940 ms，
  静态 FP8 保留填充 1.278884 ms，定点跳过填充后 1.023680 ms（减少 18.363%）。
- 另一轮同填充范围归因复核：BF16 1.362453 ms、FP8 1.048174 ms（减少 23.067%）。
  两轮有独立基线，不混合绝对耗时。外推约 1.03–1.41 秒/请求、0.43%–0.59%，未经完整请求验证。
- 偶数步校准、奇数步留出；层6/13/23/26共5份留出张量最大值超出范围。
  代表层回放不能证明全28层适用性。仅保留局部原型，没有输出投影 FP8 完整视频。
- Q6c 未启用此项。后续若继续，先补全层范围与质量验证，再判断小幅潜在收益是否值得接入。

同一研究还完成了**已纳入 Q6c 的 QKV**在一个独立竖屏视频、seed42/43上的初验：
冻结横屏校准 scale，全帧 PSNR 34.2357/34.2483 dB、SSIM 0.989269/0.989297，
累计裁剪比例 0.00001204%/0.00001272%。这不是输出投影的完整验证，
也不是最终 Q6c 全组合的跨视频验收；带统计的诊断运行不用于新的速度结论。

证据目录：`output_fp8_crossvideo_20261023_01/`；报告 `输出投影FP8与QKV跨视频验证报告.md`，
详见 `analysis/summary.json`、`analysis/output_timings.csv`、`quality/`。
