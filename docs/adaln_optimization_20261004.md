# AdaLN 与残差优化（2026-10-04）

后续完整素材验收：静态 FP8 FFN + Sage FP8 + 快速融合组合未通过两素材质量门槛，
不作为通用推荐预设；下文保留 121 帧实验范围的结果。见 [最新验收记录](l40s_validation_20261004.md)。

在上一轮 Sage FP8 + 静态 FP8 FFN + 完整 Q/K 融合之上继续优化。
不减少帧数、分辨率或采样步数，不启用缓存；允许合理数值偏差。

## 实现与筛选

新增显式算子 `rmsnorm_adaln_fast`，接收原始 hidden states，在一个 Triton kernel 中完成
非仿射 RMSNorm 和 AdaLN。保留归一化、`1 + scale`、缩放后的 BF16 边界，
关闭 FMA 合并；FP32 归约顺序允许变化。支持连续 BF16 `[1,S,2048]`、非仿射
Diffusers RMSNorm（eps=1e-6）与 `[1,1,2048]` 调制。自动模式不支持时回退，强制模式报错。
原精确调制路径保留，默认融合集合不变；两个 AdaLN 实现不能同时选择。

在 block 的两个归一化位置接入完整融合，并组合已有的精确 `gated_residual`。
缓存探针仍使用原始计算，未改变缓存行为。没有修改 Q/K/V 权重组织或扩大默认量化范围。

L40S、BF16、32640 tokens，真实模型权重与随机输入。算子在 GPU3，完整 DiT 在 GPU2：

| 测量 | 对照 | 候选 |
| --- | ---: | ---: |
| RMSNorm + AdaLN | eager 3.856 ms | 完整融合 0.417 ms |
| RMSNorm + AdaLN | 仅调制融合 3.439 ms | 完整融合 0.417 ms |
| Q/K/V 投影，包含连续输出整理 | 三次 BF16 Linear 4.264 ms | 合并 BF16 5.313 ms |
| Q/K/V 投影，包含连续输出整理 | 合并动态 FP8 4.074 ms | 合并静态 FP8 3.569 ms |

AdaLN 随机输入相对 RMSE 1.26e-5。Q/K/V 合并 BF16 更慢；合并静态 FP8 的投影误差约 3.75%，
仅作筛选，未加入正式实现。单算子收益不直接代表整请求收益。

完整 DiT 交替顺序三次测量中位数；相对误差以本轮基线输出为参考：

## 完整视频

同一 GPU2，121 帧 1920×1080、seed42、CFG3、50 steps × strength0.8 = 40 个实际去噪步。
DiT 常驻，T5/VAE CPU offload，VAE low-memory；关闭缓存和编译。先跑上一轮配置一次，
再跑完整 AdaLN + 门控残差两次，每个进程首任务前预热两步。请求包含视频读写，排除模型加载和显式预热。
