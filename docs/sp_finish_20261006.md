# SP2 / SP4 分块选择与 FFN 补零优化

沿用 BF16、SDPA、aligned GEMM 和原生归约融合。本轮保留两项经过筛选的改动：

- `MGERASE_ULYSSES_HEAD_CHUNKS=auto`：SP2 两种长度选四块，SP4 的 32640 token 选四块、
  10200 token 选两块。使用 direct 打包与输出重叠；默认仍为固定一块。
- aligned 模式下，SP4 的 10200-token FFN 下投影由补到 10200 行改为补到 3072 行。
  每卡实际 2550 行，结果截取前 2550 行；28 层及四个 rank 均验证。

自动分块仅覆盖 L40S、PyTorch 2.6.0 / CUDA 12.6、CUDA BF16、batch 1、32 heads × 64、
上述两个长度、纯 Ulysses SP2/4。已支持拓扑内的未知设备或张量形状使用一块，
TP/Ring/FSDP 仍由配置校验拒绝。选择不依赖运行耗时或空闲显存；性能测量范围是 CFG1。
不同长度的请求会重新选择；rank 报告包含策略和实际块数。
FFN 补零继续受原 aligned 硬件、模型、确定性及形状检查约束，其他输入仍走原 reference。
`compact_ffn_down_calls` 报告最近一次分支 forward 的实际执行次数，不是整个请求总数。

## 筛选证据

记录：`outputs/sp_finish_20261006/`。真实权重、固定输入，包含正负 CFG 分支和输出汇聚。
每组五次正反顺序交替，输出逐元素一致。

| SP4 Token | 上一版：四块、全长 FFN 保护 | 两块、全长 FFN 保护 | 两块、3072 行保护 | 自动选择、3072 行保护 |
| --- | ---: | ---: | ---: | ---: |
| 10200 | 0.45733 s | 0.43874 s | 0.38764 s | 0.38741 s |
| 32640 | 1.41784 s | 1.51210 s | 1.50899 s | 1.42030 s |

该表用于本轮消融，不是相对 B1 的加速表。长序列没有新增稳定收益；不能把短序列收益
外推到完整尾窗填充的 B1 工作负载。B1 的 145 帧测试两个窗口实际均为 32640 token。

SP2 最终五组复核中，固定四块 / 自动策略的长序列分别为 2.40697 / 2.39912 s，短序列为
0.48906 / 0.48863 s；自动策略保留相同计算路径，不将该波动认定为新增收益。

`sp2_chunks`、`sp4_chunks` 比较 1/2/4 块；`sp4_final` 隔离分块和补零的贡献。
`down_padding_probe.log` 中 2688 行产生数值差异，3072 行及更大候选通过初筛；
`down_all_layers.log` 覆盖 28 层、四个 rank 的真实权重与 GELU 输入。最终验收依赖
完整 DiT 和实际去噪视频，不能只凭随机算子探针放宽数值保护。

`forward_audit.json` 核对所有候选 rank 的实际块数、补零次数与融合回退。
forward 测量后补齐了启动层 `auto` 参数校验和测试，数值 kernel 未变。
`tests.log` 为 28 项通过、22 项可选进程/GPU 测试跳过；`integration_tests.log` 为 31 项通过；
新增启动层测试在 `config_tests.log` 中通过。真实多卡执行由 forward 与视频验收覆盖。

## 未采用的候选

残差加法与平方计算融合通过逐元素一致性检查，但五轮微基准中，2550 / 5100 / 8160 行
分别从 0.101 / 0.189 / 0.310 ms 变为 0.110 / 0.208 / 0.413 ms；16320 行仅从
0.948 降到 0.910 ms。未接入运行时。原型和记录保存在 `residual_candidate.py`、
`residual_kernel_paired.log`，没有新增残差融合开关。

接收端重排仍是后续候选，本轮未把未测量的布局更改上线。共享主卡 rank 0 仍按窗口
管理权重驻留，以维持原有 24 GiB 任务显存验收口径；这不是所有 DiT 权重全程驻留。

## 复现

```bash
# SP4；SP2 改成 sp2_native_rms 和 --devices 0,1。
MGERASE_ULYSSES_HEAD_CHUNKS=auto MGERASE_ULYSSES_OUTPUT_OVERLAP=1 \
uv run --no-project python -m entrypoints.cli.benchmark_l40s \
  --run-dir outputs/sp4_auto_b1 --profile sp4_native_rms --devices 0,1,2,3 \
  --prompt 'There is a bridge over the lake.' --seed 42 --repeats 1
```

基准自动启用 direct；直接使用 CLI 或服务时另设 `MGERASE_NCCL_PACKING=direct`。
3072 行保护随已显式启用的 `--sp-linear-mode aligned` 生效，无新增用户参数。
固定 1/2/4 块和 reference 模式仍可使用。
