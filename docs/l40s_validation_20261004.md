# L40S 24 GiB 验收记录

本轮按每张卡上任务进程占用之和检查 24 GiB，包括加载、预热、推理和退出；
使用 NVML 约 0.1 秒采样，同时保存 allocated/reserved 与整卡使用量。
采样峰值不是连续监控的数学上界；`--cuda-memory-limit-gib 22` 只限制每进程 PyTorch 分配器，
外部 CUDA/NCCL 分配及同卡多进程总量仍须实测。

## 输出通信流水

新增可选 `MGERASE_ULYSSES_OUTPUT_OVERLAP=1`，在 head 分块路径中先排入下一块输入交换，
再交换当前块输出；下一块计算只等待自身输入事件。所有 rank 使用相同 collective 顺序，
结果重排恢复 rank-major/head-major 顺序，跨流张量保持至安全回收点。

双卡真实 NCCL 检查覆盖 2/4 分块、变长和非连续输入、保留输出不被复用覆盖，以及异常后重试，
