# 开发路线

当前已提供 CLI、HTTP 服务、peer CFG/SP、独立 NCCL DiT 多进程与完整/组件编译入口。
本轮计算、内存、通信与缓存优化的实施及筛选结果见[推进记录](optimization_progress_20261002.md)。
下表保留更长期的跨硬件、多素材和产品方向，不代表当前验收范围；已实现能力及限制见[性能说明](performance.md)。

## 本轮 L40S 验收已完成

[收敛计划](l40s_completion_plan.md)中的实现、筛选和验收已完成，README已按L40S单卡、双卡、四卡全文重写。
七组正式矩阵共40条请求输出均与单卡BF16参考一致，最高单卡任务进程合计峰值21.746 GiB，满足24 GiB目标。
单视频推荐配置中位数分别为420.23 / 241.17 / 195.93秒；批量吞吐、启动成本与完整范围见[验收记录](l40s_validation_20261004.md)。

双卡CFG2和四卡reference另通过两个原始素材、两个seed的输出一致性验证。
输出通信重叠已纳入四卡推荐；近似attention/FP8/快速融合、sharded SP及缓存候选未通过质量门槛，推荐关闭。
WebUI、取消恢复和CPU/GPU专项验证已完成，检查范围见验收记录。

## 后续方向

| 方向 | 计划 | 阶段目标 |
| --- | --- | --- |
| **消费级显卡适配** | 优化 VAE 编解码峰值、激活生命周期、窗口缓存和 CPU/GPU 搬运；完善 VAE tiling、流式处理及低显存预设 | 优先支持 24 GiB 显卡稳定完成 1080p 视频，再评估 16 GiB 配置的分辨率、帧数和速度边界 |
| **WebUI** | 已提供 `/ui`：视频/mask 上传、静态区域画笔、提示词、任务进度、预览、取消与下载 | 浏览器流程与真实 L40S 服务的运行中取消/恢复已通过；性能预设继续随扩大验收收敛 |
| **单卡性能** | 分阶段分析文本编码、去噪、VAE 和数据搬运；继续优化 attention、局部 compile、算子融合及预取调度 | 在固定质量门槛下改善稳态延迟，并分别报告冷启动、warmup 和正式推理耗时 |
| **多卡性能** | 优化 CFG/SP 的通信与计算重叠、持久化副本和拓扑选择；基于已实现的 NCCL 和 CFG × SP 四卡组合，细分 DiT 计算/通信与非去噪开销 | 本轮L40S 2/4卡吞吐、延迟、显存和故障恢复已验证；后续扩大硬件拓扑与素材范围 |
| **TeaCache / CacheDiT 调优** | 已完成多素材、后部实算、连续复用限制及保守阈值筛选；本轮候选均未通过，推荐关闭 | 后续有新的质量保护方法时再评估质量—速度关系，减少闪烁与局部结构损失 |
| **FP8 量化** | 已提供 native/tensorwise/static 三种 FP8、GELU 融合与单卡卸载组合；已完成本轮多素材、多窗口与静态范围审计，推荐 BF16；见 [FP8 优化](fp8_optimization_20261004.md) 和 [AdaLN 融合](adaln_optimization_20261004.md) | 后续评估新的校准与精度保护方案；低饱和率不能代替输出质量验证 |
